# ATELIERGROUPE website brief

## Goal
Create a robust, minimal, static Astro website for a young architectural practice.

## Structure
- `/` landing image cover
- `/about` information fiche
- `/notes` notes/articles fiche

## Menu
Shared bottom menu on `/about` and `/notes`:
email / t+ / about / notes

Active current page is bold.
No intra-page section navigation in the main menu.

## Homepage
- centered ATELIERGROUPE title
- approx. 9 WebP images
- random first image
- random non-repeating sequence
- smooth crossfade every 5s
- clicking ATELIERGROUPE goes to `/about`

## About
Sections:
- ABOUT
- NEWS
- PROJECTS
- OFFICE

News ordered by manual rank/index, not published date.

## Notes
Independent page.
Mostly text.
Articles ordered by manual rank/index.
